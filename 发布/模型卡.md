# 模型卡

数字都是示例，配置包 `TZ-cfg-2026.10-示例`。这一页说明模型现在能回答什么。原则和 10 月的四档在 [设计说明.md](设计说明.md)。

| 字段 | 内容 |
| :-- | :-- |
| 名称 | 产量成本模拟，月度模型在 `v5.2/model_builder.py`，按天核对在 `v5.2/daily.py` |
| 用途 | 每个车间每个月选一个 JPH × 班次，写出成本和科目。给讨论用。它不下排产指令 |
| 不适用 | 参数还是自设值时的预算；冲压和总装的按天开停；单台设备；把按天成本和月度成本加在一起；把借调净额写成已经省下 |
| 数据 | `v5.2/data/`。可信等级是自设值。`plant_check` 为 L2：可以测算，没有 `actual.csv`，不能回测 |
| 方法 | PuLP + HiGHS（没有就用 CBC）。月度设定间隙 0.01%，按天默认 0.1%。种子 1，线程空着时用 1。每次求解写下界、间隙、是否触到时限。决策卡页眉带参数包短哈希，以及 A05–A10 是默认关闭还是已打开 |
| 对外一句 | 见 [术语与口径.md](术语与口径.md)。基准总成本 44,287 万元、12 万台、单车 3,691 元 |
| 已知局限 | A05–A10 和月度粗参数默认关闭，少开班的节省是上限。借调净额未验证。需求 −10% 这次运行与 golden 差约 189 万元。月度层和按天层对不上的科目在 [样例/未验证清单.csv](样例/未验证清单.csv) |
| 覆盖 | 哪些方向已经进求解，见 [样例/方向覆盖表.csv](样例/方向覆盖表.csv)。现有场景动了哪些旋钮，见 [样例/场景方向.csv](样例/场景方向.csv)。电价、停线、停工发薪各只出现在一个场景里，没有为了凑次数而新造场景 |
| 降级 | 旋钮相对 1 的变化在 5% 到 10% 时写观察，超过 10% 时先看 [样例/翻转表.md](样例/翻转表.md)。求解结果仍保留，不自动改成另一套班次。分档还没有业务签认 |
| 价值 | 只从 [样例/价值台账.csv](样例/价值台账.csv) 取数。示例行全部是模拟，计入合计都是「否」。已实现节省还没有 |
| 采纳 | [样例/采纳与改动日志.csv](样例/采纳与改动日志.csv) 仍是空表。实际排法表 [样例/实际排法.csv](样例/实际排法.csv) 也还是空的，所以没有历史回放 |
