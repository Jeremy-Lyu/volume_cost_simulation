# 翻转表：五个标准场景

数字都是示例，配置包 `TZ-cfg-2026.10-示例`。来源是 [results_summary.md](results_summary.md)，不是新的求解。这里只回答「相对基准，总装的档变了没有」。从 0 到 −10% 的临界百分比没有重解。

| 场景 | 总成本（万元） | 总装 | 相对基准 |
| :-- | --: | :-- | :-- |
| 基准 | 44,287 | 全年 36×2 | — |
| 需求 +10% | 47,399 | 全年 36×2 | 总装不改。涂装多个月改成三班 |
| 需求 −10% | 41,155 | 全年 30×2 | 总装改档。焊装也改成全年 30×2 |
| 电价 +20% | 45,060 | 全年 36×2 | 总装不改。焊装前几个月改成 30×2 |
| 工资 +5% | 45,127 | 全年 36×2 | 总装不改。焊装前几个月改成 30×2 |

需求 −10% 这一行是这次运行的 41,155 万元。`golden.csv` 里同场景的旧基线是 40,966 万元。差约 189 万元时，先看时限和间隙。

两个方案的差额小于决策卡上的求解间隙时，不要说谁更优。这些差额不要加在一起，也不要和按天层的停线节省加在一起。台账在 [价值台账.csv](价值台账.csv)。
