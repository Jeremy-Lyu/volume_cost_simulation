# 演示样例（示例数据）

这些文件是从本机一次求解里拷出来的，方便在仓库里直接打开，不必先跑完 `run.py`。完整的 `v5.2/output/` 仍被 `.gitignore` 排除，本地重算后会重新生成。

| 文件 | 内容 |
| :-- | :-- |
| [设计走读.md](设计走读.md) | 用基准的 10 月，把设计说明落到四车间各一档 |
| [成本模型_示例.xlsx](成本模型_示例.xlsx) | 蓝字输入、黑字公式。改假设后，单车和旺季差额会重算。求解结果是引自样例的输入，本表不重新求解 |
| [results_summary.md](results_summary.md) | 五个标准场景的总成本与班次 |
| [scenario_summary.csv](scenario_summary.csv) | 同上，表格口径 |
| [决策卡_开停校正.md](决策卡_开停校正.md) | 六个粗参数打开后的决策卡（含「未验证」借调） |
| [采纳与改动日志.csv](采纳与改动日志.csv) | 空表。计划会记下推荐、实际、是否采纳和原因。原因只用：隐性约束、不理解、习惯、数据错、其他。还没有已实现的节省 |
| [价值台账.csv](价值台账.csv) | 已经发表过的差额。状态是模拟或未验证，计入合计都是「否」 |
| [翻转表.md](翻转表.md) | 五个标准场景里，总装的档变了没有 |
| [方向覆盖表.csv](方向覆盖表.csv) | 每个方向是已建模、默认关闭，还是先不做 |
| [场景方向.csv](场景方向.csv) | 现有场景各动了哪些旋钮。电价、停线、停工发薪各只出现一次 |
| [未验证清单.csv](未验证清单.csv) | 月度层和按天层不能相加的科目。现在是白车身缓存上限和借调净额 |
| [实际排法.csv](实际排法.csv) | 只有表头。列是类型、日、车间、JPH、班次、状态。填了以后按天层只计价，不重新选班次。现在是空的 |

金额不能当成工厂实绩。
