# 结果契约（vcs_run / 0.1）

看板或编排层只读消费这一份字段。金额只来自已求解结果。本仓库用 `v5.2/run_record.py` 写出 JSON，不启 HTTP，也不写回 MES。

## 关联键

| 字段 | 含义 |
| :-- | :-- |
| 场景ID | 场景名或自定义名称 |
| 配置版本 | `plant.json` 的 `config_version` |
| 代码版本 | git 短哈希，或源码短哈希 |
| 参数哈希 | `data/` 内容的 8 位短哈希 |
| 结果哈希 | 这次班次与成本打包后的哈希 |
| 运行时间 | 写出快照的时间 |

目标值如果进看板，只取已发布的测算结果，不要另写固定目标。

## 必带证据

| 字段 | 含义 |
| :-- | :-- |
| 就绪度 | `plant_check` 的 L0–L3 句子 |
| 假设开关 | A05–A10 默认关闭，或已打开的编号 |
| 口径 | 可信等级（取用到参数里最低一档） |
| 精度 | 间隙、是否触到时限、种子、线程 |
| 上限 | 粗参数关闭时，少开班的节省是上限 |
| 未验证 | 借调净额等不能进合计的项 |

## 结果本体

| 字段 | 含义 |
| :-- | :-- |
| 基准 / 本次 | 运营成本、产量、状态；本次还有单车、延期、流失、班次列表 |
| 比基准_万元 | 本次运营成本 − 基准运营成本 |
| 旋钮 | 相对基准的覆盖 |
| 翻转 / 降级 / 跨尺度 | 决策卡上的提示句 |
| 示例数据 | 恒为 true，直到工厂实数接入 |
| 不做 | 固定三条：不替代 MES/APS；不自动下达；不把模拟差额写成已实现 |

## 从哪来

| 产物 | 命令 |
| :-- | :-- |
| 决策卡 `.md` + 快照 `.json` | `cd v5.2 && .venv/bin/python -m workbench.api --scenario 开停校正` |
| 五场景汇总（含 Gap 列） | `cd v5.2 && .venv/bin/python run.py` → `output/scenario_summary.csv` |
| 就绪度 | `cd v5.2 && .venv/bin/python plant_check.py` |

样例目录里的 `scenario_summary.csv` 仍是旧列（无 Gap）。以 `run.py` 现写列为准。开停校正决策卡样例应含「能不能用」一节。
