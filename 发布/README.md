# 发布

给人读的材料都在这个文件夹。项目为什么做、要回答哪四个问题、一次测算分哪几步，写在仓库首页 [README.md](../README.md)。先读 [设计说明.md](设计说明.md)：原则、基数该谁改、哪些假设还标着 ⚠。数字是示例，配置包 `TZ-cfg-2026.10-示例`。代码在上一级 [`v5.2/`](../v5.2/)，命令从那里执行。
