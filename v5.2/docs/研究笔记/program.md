# 产量成本：场景、极限、假设的研究循环

把研究循环用在产量成本模型上：每次只改情景，跑求解，用同一把尺子决定留下还是丢掉。不改求解器，不改「成本越低越好」的目标。工厂改基数或公式的步骤在 `DOC/工厂改数与重算指南.md`，不走这条研究循环。

## 可以改

- `factory_analysis.py` 里的情景、解读和给工厂的建议。

## 不要改

- `model_builder.py`、`cost_functions.py`、`engine.py`、`prepare` 一类的求解和评价。
- 为了让数字变好看而改目标函数或惩罚。

## 尺子

对照该情景自己的参照，看三件事：

- 年底交不出的台数变了 100 台以上
- 晚交变了 500 个「一台晚一个月」以上
- 制造费变了 100 万以上

三条都不动：这条假设不改变建议，记 discard。有一条动了：留下，并写成一句人话。两条结果完全一样（例如「每月加人 2%」和「之后完全不能加人」都是多 81 万）：留下，但要写明模型没分开这两件事。

## 一轮怎么做

1. 从 `data/假设登记表.md` 里挑一个还没在「建议会变的产量」上验过的假设，或一个更极端的订单。
2. 在情景表里加一条，参照写清楚。
3. 只跑新增情景（旧结果有缓存）。
4. 把结果补进同目录的 `results.tsv`：情景、状态 keep 或 discard、一句话。
5. keep 的写进 `output/analysis/决策说明.md`。discard 的不写进建议，可以留在情景表里，避免下次重复算。
